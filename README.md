# model_v2 — перекрёсток без светофора

Симулятор того, как водители сами договариваются о проезде нерегулируемого
многополосного перекрёстка: кто кого пропускает, кто подкрадывается, кто едет.

Под капотом каждый водитель в каждый момент решает одно — с каким ускорением
ехать. Это ускорение получается как самое строгое из нескольких ограничений:
держать желаемую скорость, не въехать в идущего впереди, уступить на
пересечении, в крайнем случае — ударить по тормозам. А привычные «едет /
уступает / крадётся» — это уже ярлыки, которые мы вешаем на результат, а не
отдельные куски кода.

Вся математика расписана в `../mathematical_model.tex`.

## Как запустить

Из корня проекта `intersection/`:

```bash
python -m model_v2.main            # с картинкой
python -m model_v2.main --headless 120   # без картинки, прогон на 120 секунд
```

Нужны `numpy` и `matplotlib`.

## Что нажимать в окне

- **пробел** — пауза;
- **0 / 1 / 2** — сколько подробностей сыпать в консоль;
- **ползунок снизу** — скорость проигрывания.

В консоль попадают только моменты, когда водитель **меняет** решение, например:

```
[t= 25.80] #8  едет  —  уступаю #11 (по ПДД)
```

## Где что лежит

- `config.py` — все настройки (скорости, ускорения, пороги);
- `priority.py` — правила ПДД и оценка «куда поедет сосед» по его поворотнику;
- `decision.py` — собственно выбор ускорения;
- `simulation.py` — один шаг мира: появление машин, прогноз, движение, счётчики;
- `main.py` — запуск, отрисовка и прогон без графики.

Геометрию дорог (`geometry.py`) и саму машину (`car.py`) берём как есть из
соседнего пакета `model/` — их не трогали.

## Что чаще всего крутят в `config.py`

- `SEED` — меняешь число, получаешь другой сценарий движения;
- `T_HORIZON` — на сколько секунд вперёд водитель вообще смотрит (дальних
  игнорирует);
- `SPAWN_RATE_PER_LANE` — насколько плотный поток;
- `A_MAX_POS`, `A_BRAKE_CMF`, `A_BRAKE_MAX` — разгон, обычный тормоз, аварийный;
- `RHO_*`, `TAU_*`, `SIGMA_*` — разброс характеров водителей.
